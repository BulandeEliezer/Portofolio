smartsokrab.com · smartsokrab.com/ar/
Technical SEO · Arabic localization · Saudi Arabia

Smart Sokrab: SEO fix across the whole site and a full Arabic version

Problem

An SEO audit flagged heading errors on almost every page. A site-wide chat widget was adding a hidden H1 to 75 pages, and the real page titles were not H1s at all.

What I did

Traced the problem to the widget's code and corrected its markup. Then, working through the WordPress REST API with backups, I made the first Elementor heading on each page its H1 and fixed the missing meta fields. I also built a complete Arabic right-to-left version of the site.

Result: all 84 pages now have exactly one correct H1, and the Arabic site is live at /ar/ with 85 localized pages.

chinaarabic.com
Arabic RTL platform · Astro · CI/CD

ChinaArabic.com: an Arabic-first guide to China, built from a 37-page brief

Problem

The owner had a detailed 37-page specification for a fast Arabic content platform. It required strict image licensing, unfinished content kept off the live site, and no manual uploads to production.

What I did

Built the site in Astro with a right-to-left design system. Every image goes through an approval step, and draft guides only appear in preview. I set up GitHub Actions so that every push to the main branch deploys automatically over secure FTP (FTPS).

Result: the brief was implemented in full and went live on 29 Sep 2026. Updates now deploy automatically with each code push.

Kigali · Hospitality SEO
Hospitality · SEO audit · Content strategy

The Hut Hotel Rwanda: a content plan driven by search data

Problem

The hotel's pages were competing with each other for the same searches. Some pages got plenty of search impressions but almost no clicks.

What I did

Audited the site using Google Search Console data and fixed overlapping pages and schema issues. I wrote and published a 20-article cluster about stays, dining and travel in Kigali, then planned and scheduled a 12-article calendar for Oct–Dec 2026.

Result: clearer, non-competing page targets, a 20-post cluster live and a quarter of SEO content already scheduled.

wayan.rw/fr/
Law firm · French localization

WAYAN: a French version that matches the English site exactly

Problem

A Rwandan law and advisory firm needed a French site that looked exactly like its English one, without rebuilding the design from scratch.

What I did

Copied the live Astra/Elementor pages and translated only the text, so the layout, styling and responsiveness stayed exactly the same.

Result: 28 French pages and posts live at wayan.rw/fr/, matching the original design.
